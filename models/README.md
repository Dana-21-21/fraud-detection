# Models Directory

This folder is used to store trained machine learning models.

## Purpose

During the modeling phase, we will train multiple models for fraud detection, such as:
- Logistic Regression (baseline model)
- Random Forest
- XGBoost / LightGBM (ensemble models)

The best-performing model will be saved in this folder for reuse and potential deployment.

## Contents

- Trained model files (e.g., `.pkl` or `.joblib`)
- Final selected model
- Model checkpoints (if needed)

No files are currently stored here because model training will be completed in Task 2 of the project.
